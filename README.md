# 🥦 BROCCOLI: Kingdom Clash

لعبة استراتيجية بالوقت الفعلي أصلية: مزارع تنتج براعم‑جنوداً، ترسلهم على شكل موجات للاستيلاء على المباني.
الحالة الحالية: **المرحلة P1 (نواة قابلة للعب)**. التفاصيل الدقيقة لما أُنجز وما بقي في [`docs/STATUS.md`](docs/STATUS.md).

## التشغيل على Windows (PowerShell)

المتطلبات: Node.js 22 أو أحدث.

```powershell
npm install        # مرة واحدة
npm run dev        # يشغّل اللعبة ويعيد البناء عند أي تعديل
```

يطبع الأمر عنوانين:

- على الكمبيوتر: `http://localhost:5173`
- على الآيفون (نفس شبكة Wi‑Fi): `http://<IP الكمبيوتر>:5173` — افتحه في Safari وأدر الهاتف أفقياً.

إن لم يفتح من الهاتف: اسمح لـ Node.js في جدار حماية Windows (شبكة خاصة). لمعرفة الـIP يدوياً: `ipconfig` ثم سطر IPv4.
لتغيير المنفذ: `$env:PORT=8080; npm run dev`.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم تطوير على كل واجهات الشبكة |
| `npm run build` | بناء `dist/` (index.html + app.js) وملف واحد مستقل `dist/broccoli.html` |
| `npm run test` | اختبارات المحاكاة (20 اختباراً) |
| `npm run test:e2e` | مباراة حقيقية آلية في Chrome بمقاس هاتف أفقي ولمس (يتطلب `npm run build` و Chrome مثبتاً) |
| `npm run lint` | فحص الأنواع TypeScript |

`dist/broccoli.html` ملف واحد يعمل بفتحه مباشرة أو برفعه لأي استضافة ثابتة (HTTPS).

## طريقة اللعب

- اسحب من مبنى تملكه إلى أي مبنى لإرسال الجنود؛ أفلت على أرض فارغة للإلغاء.
- أزرار 25/50/75/100% يسار الشاشة تحدد النسبة.
- لمسة تحدد مبنى، ثم لمسة على هدف ترسل. ضغط مطوّل أو إطار أو زر «الكل» لتحديد عدة مبانٍ.
- مبنى واحد محدد ⇒ أزرار الترقية/التحويل يمين الشاشة.

## بنية المشروع

```
apps/client/            واجهة اللعبة (Canvas 2D + DOM HUD)
  src/render/           الرسم: فن إجرائي أصلي، جسيمات، موجات
  src/audio/            مؤثرات صوتية مولّدة
  src/ui/               الترجمة عربي/إنجليزي
  src/game.ts           حلقة ثابتة 20 tick/ث، لمس، HUD
packages/simulation/    محاكاة حتمية خالصة (بدون DOM): قتال، مسارات، AI
packages/content/       balance.json والخرائط JSON
tests/                  اختبارات المحاكاة
scripts/                build / dev / e2e
docs/                   الخطة والحالة
```

كل أرقام التوازن في `packages/content/balance/balance.json`؛ إضافة خريطة = ملف JSON جديد + سطر في `packages/simulation/src/index.ts`.
