# مصادر الأصول — BROCCOLI

**كل الرسومات والأصوات من إنتاج المشروع نفسه، مولَّدة بالكود وقت التشغيل. لا توجد ملفات صور أو صوت خارجية، ولا شيء مرخَّص من طرف ثالث، ولا أي أصل من لعبة أخرى.**

| الأصل | المصدر | الملف |
|---|---|---|
| المباني (قرية البراعم، برج الشوك، الحدّادة) وكل مستوياتها | رسم إجرائي بمسارات Canvas 2D | `apps/client/src/render/art.ts` |
| الخامات (خشب بألياف، حجر بحواف فاتحة، أوراق بلمعة حافة) | دوال `timber` / `masonry` / `floret` | `art.ts` |
| الأعلام والشارات وأشكال الفرق | `flag` / `emblemShape` / `banner` | `art.ts` |
| جندي البروكلي: جري ×4، ضرب ×2، إصابة، سقوط؛ 4 فرق + محايد | `makeSoldierSheets` (يُرسم مرة عند التحميل إلى أوراق sprites في الذاكرة) | `art.ts` |
| التضاريس: هضبة، حافة ترابية، صخور، مصاطب، طرق، برك، أشجار | `paintBackground` + `drawPond/drawRock/drawTree/drawWater` | `renderer.ts`, `art.ts` |
| الجسيمات والمقذوفات والمؤثرات | رسم مباشر مرتبط بأحداث المحاكاة | `renderer.ts` |
| كل المؤثرات الصوتية | تركيب Web Audio (مذبذبات + ضجيج مفلتر) | `apps/client/src/audio/sfx.ts` |
| الأجواء (حفيف، طيور، ماء) | ضجيج مفلتر بـLFO + زقزقات مولّدة عشوائياً | `sfx.ts` |
| الموسيقى (طبقة هادئة + طبقة معركة) | متتالية خماسية أصلية مولّدة بالكود | `sfx.ts` |
| الخطوط | خطوط النظام (`system-ui`) | — |
| الرموز في الواجهة (🥦 🍃 ⏱ ⚑ …) | محارف Unicode تعرضها خطوط الجهاز | — |

## الصيغة والمحرك
المحرك Canvas 2D، لذلك «صيغة» الأصول هي دوال رسم. الأجزاء الثابتة من المباني تُخبَّز مرة لكل (نوع، مستوى، مالك) في sprite مخبأ بدقة الشاشة ويُعاد استخدامه؛ الأعلام ورأس البرج والنار والدخان تُرسم حيّة. الجنود أوراق sprites مخبوزة بثلاثة أضعاف الدقة.

## ما يلزم لنسخة إنتاجية مرسومة يدوياً
أطلس PNG/WebP للمباني والجنود (8 اتجاهات)، وتسجيلات صوتية حقيقية أو مكتبة مرخّصة. نقاط الاستبدال: `drawBuilding` و`makeSoldierSheets` و`sfx`.
