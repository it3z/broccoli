# الأونلاين — BROCCOLI

## كيف يعمل
- `apps/server/src/server.ts`: سيرفر Node بلا اعتماديات (WebSocket مكتوب يدوياً على `node:http`). يشغّل **محاكاة TypeScript نفسها** لكل غرفة بمعدل 20 tick/ث، ويرسل لقطة الحالة كاملة لكل لاعب كل tick.
- العميل لا يشغّل المحاكاة أونلاين: يرسل الأوامر فقط ويرسم لقطات السيرفر (`applySnapshot`).
- كل أمر له رقم متصاعد؛ السيرفر يتجاهل أي رقم سبق أن رآه (لا تكرار بعد إعادة الإرسال)، ويستبدل رقم اللاعب في الأمر بمقعد الاتصال (لا يمكن انتحال لاعب آخر)، ويحدّ 20 أمراً/ث.
- إعادة الاتصال: عند الانضمام يحصل العميل على رمز سري للمقعد (محفوظ في `sessionStorage`). انقطاع الشبكة → يعيد الاتصال تلقائياً بنفس المقعد؛ إعادة تحميل الصفحة → زر «العودة للمباراة». المقعد محفوظ 60 ثانية (`GRACE_MS`) ثم يُعدّ اللاعب مستسلماً.
- 1 ضد 1 على الخريطة المختارة (مرج الربيع افتراضياً)، 2 ضد 2 على الغابة العميقة (الزاويتان اليسريان ضد اليمنيين). البذرة الذهبية مفعّلة، ولكل مقعد بطل.

**Colyseus:** طُلب في المواصفات لكنه لم يُستخدم لأن تنزيل الحزم مغلق في بيئة البناء. البروتوكول بسيط (create / join / rejoin / cmd ↔ joined / lobby / start / snap / end)، ويمكن نقله إلى Colyseus لاحقاً دون تغيير المحاكاة.

## تجربة محلية (Windows / PowerShell)
```powershell
npm install
npm run build
npm run server          # http://localhost:8787  (WebSocket على /ws)
```
افتح `http://localhost:8787` في متصفحين (أو من الآيفون على نفس الشبكة: `http://<IP الكمبيوتر>:8787`) ← أونلاين ← «غرفة 1 ضد 1» ← شارك الرمز ← الثاني يكتب الرمز ← «انضمام». المباراة تبدأ حين تمتلئ المقاعد.

اختبار آلي: `npm run test:online` (يشغّل السيرفر و2 ثم 4 متصفحات مستقلة).

## الاستضافة العامة
صفحات GitHub ثابتة ولا تشغّل سيرفراً. السيرفر خدمة منفصلة تحتاج استضافة تدعم WebSocket ويعمل باستمرار، مثل Render أو Railway أو Fly.io أو أي VPS:
1. اربط المستودع `it3z/broccoli` بالخدمة.
2. أمر البناء: `npm install && npm run build` — أمر التشغيل: `npm run server` — المنفذ من متغير `PORT`.
3. تحصل على عنوان مثل `https://broccoli-xyz.onrender.com`. هذا العنوان نفسه يخدم اللعبة، والأونلاين يعمل منه مباشرة.
4. للعب من رابط GitHub Pages (`/broccoli/preview/`): في شاشة أونلاين اكتب عنوان السيرفر `wss://broccoli-xyz.onrender.com/ws` (يُحفظ في الجهاز).
